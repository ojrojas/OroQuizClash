## MASTER.md Contract — Required Sections

Generated by `ui-ux-pro-max --design-system -f markdown` and enriched with our FRs. Must contain at minimum:

1. **Header**: `Project: QuizArena | Version | Date | Validated by ui-ux-pro-max | Addendum 2 reference`
2. **Visual Direction**: Product→UX→System flow, mood (Exciting/Premium/Trustworthy/Competitive/Immersive/Accessible), avoid list (generic SaaS/Bootstrap, AI purple, glass/neon excess, clutter)
3. **Pattern & Style**: Pattern `Hero + Testimonials + CTA` (gaming) + `Enterprise Gateway` (admin) OR synthesized hybrid; Style `Vibrant & Block-based` + `Data-Dense Dashboard` with mode support light|dark
4. **Color Palette**: Table `Role | Hex | CSS Variable` + contrast notes + gold leaderboard + blue data; `forced-colors` fallback; light+dark contrast independently verified
5. **Typography**: Heading/Body families + Google Fonts import + CSS import + mood/best-for
6. **Key Effects**: gaps, hover, scroll-snap, chart zoom, tooltips, filter animations per style
7. **Spacing / Radius / Elevation / Motion**: Scales + tokens + presets + GSAP snippet tier (standard 7)
8. **Component Inventory**: Button, Input, Select, Table, Card, Modal, Drawer, Badge, Tabs, Progress, Timer, QuestionCard, AnswerOption, Leaderboard, Toast — with anatomy/variants/states
9. **States**: Global `Loading...Completed` + Game `QuestionActive...Consolation` (§9)
10. **Responsive Rules**: 375/768/1024/1440 + gutters 16/24/32 + adaptation table
11. **Accessibility Rules**: WCAG 2.2 AA (4.5:1, 3:1 large, 3:1 focus), keyboard, aria, forced-colors, touch 44pt, no solo-color, reduced-motion
12. **Anti-Patterns**: §13 list
13. **Application Overrides**: Admin (light, dense, professional) vs Player (dark cinematic, immersive, progression/tension) — shared primitives, different semantics
14. **Architecture Note**: `QuizArena.Admin` (Blazor .NET 11) + `QuizArena.Player` (Angular 22) → `QuizArena.Api` (BuildingBlocks) — never direct DB
15. **Visual Quality Gate**: Checklist §12
16. **References**: Constitution v1.1.0, constitution-addendum.md, constitution-addendum2.md, oroidentityserver-specification, buildingblocks

## Page Override Contract (`pages/*.md`)

Each `pages/<name>.md` contains **only deviations from MASTER**:

```markdown
# Page: Game Screen — Player

**Overrides MASTER**: `design-system/MASTER.md`

## Deviations
- Layout: centered cinematic, progression 3/5, timer sticky
- Components: QuestionCard + Timer + Progress + Leaderboard (optional)
- Motion: roundTransition 500, timer-pulse on warning/critical

## Tokens Used
- `color.primary.500`, `typography.display`, `spacing.4` ...

## A11y Notes
- Countdown `aria-live=polite`, no solo-color
```

If no file exists for a page, use MASTER exclusively.

## Tokens Files Contract

- **`design-tokens.json`**: Style Dictionary format, three layers, versioned semver, primitive hex only in primitives; semantic `value: var(--color-blue-600)`; component `value: var(--color-primary)` — no literals outside `primitive`.
- **`design-tokens.css`**: Generated via `node scripts/generate-tokens.cjs --config design-system/tokens/design-tokens.json -o design-system/tokens/design-tokens.css` → `:root { --color-primary: var(--color-blue-600); ... }` + theme overrides `[data-theme="player"]`.

## Validation Contract

- `node scripts/validate-tokens.cjs --dir design-system/ --dir src/` — fails on hex literal outside `tokens/` (0 allowed).
- `axe` — light + dark independent; 375 + 1440 + reduced-motion.
- `pnpm build:tokens` — <1 s.

## Governance (SDD)

- Major visual change → update `MASTER.md` via SDD (new SPEC or ADR) → bump `version` → regenerate `design-tokens.json` → re-validate → PR requires Visual Quality Gate pass.
- `constitution-addendum2.md` §14 is normative: `MASTER.md` is the single global source; app code must import `design-tokens.css` and use `var()` exclusively.
